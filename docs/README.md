# Documentation Map

Start with the smallest authoritative surface.

## Current Product

- `WORKFLOW.md`: request shape, planning, judgment, operation, validation, and
  completion.
- `ARCHITECTURE.md`: current product, code, state, update, and ownership
  boundaries.
- `auto-skills.md`: auto-skills extension behavior (pre-existing doc).
- `product/`: current product behavior.
- `decisions/`: lasting choices future work must inherit.
- `plans/`: durable working-memory documents for work that needs one (distinct
  from the root `plans/` directory, which holds dated implementation plans for
  past work).
- `templates/`: optional decision and plan structures.

## Consumer-Owned Truth

The root `README.md`, `extensions/`, `scripts/`, `test/`, root `plans/`, and
this repository's code and tests remain authoritative. Harness does not
overwrite those with upstream assumptions.
